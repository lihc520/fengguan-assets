# fengguan-assets

Public reference assets for the generated animation project `Fengguan`.

## Layout

- `assets/scenes/`: palace environment references
- `assets/characters/`: character turnaround references
- `assets/props/`: key prop turnaround references
- `assets/manifest.json`: stable asset names, paths, and Raw URLs

All files in this repository are intentionally public. API keys, environment
files, prompts, scripts, and private project documents must not be committed.
